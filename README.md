#  Personal Portfolio Website

This is my personal developer portfolio showcasing my skills, projects, and experience as a Software Developer.

---

## About the Project

This portfolio serves as a central place where I present:
- My technical skills
- Projects I have built
- Contact information
- Resume/CV download

It is designed to be clean, responsive, and user-friendly.

## 🧠 Features

-  Home section with introduction
-  About me section
-  Skills showcase (Frontend & Backend)
-  Projects section with live demos
-  Downloadable CV
-  Contact form / social links
-  Fully responsive design
